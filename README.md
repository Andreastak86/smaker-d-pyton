# Smaker det pyton?

Spill laget i Python med Pygame og slangen Pål.

Pål har ett mål i livet: spise ting.

Problemet er at Pål verken har dømmekraft, kostholdsplan eller nevneverdig respekt for hva som faktisk regnes som mat.

Gammelost smaker pyton!  
Dravle er også litt pyton.

Men hva mer smaker pyton?

## Gameplay

Beveg Pål rundt på skjermen og spis det du finner.

Noen ting gir poeng.  
Andre ting gir sannsynligvis anger.

På dette tidspunktet vet heller ikke utvikleren helt hva Pål kommer til å spise senere i spillet.

Det er kanskje like greit.

## Controls

WASD / Arrow keys – Flytt Pål  
ESC – Avslutt før Pål gjør noe vi alle kommer til å angre på

## Current state

Pål er foreløpig en grønn firkant.

Dette skyldes ikke kunstnerisk retning.

Vi har bare ikke tegnet en slange ennå.

## Development philosophy

1. Få det til å virke.
2. Gjør det morsomt.
3. Gi Pål tilgang til ting han absolutt ikke burde spise.
4. Observer konsekvensene.
